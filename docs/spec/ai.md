# 🤖 AI 서비스 명세서 — 코드 리뷰 기준서 (AI Feature Review Reference)

> [!IMPORTANT]
> **이 문서는 코드 리뷰 전용 참고 자료입니다. 기능 개발 지시서가 아닙니다.**
> - AI 에이전트는 이 문서를 근거로 기능을 **구현·생성·수정하지 않습니다.**
> - 개발자가 직접 작성한 코드가 아래 규격을 잘 따르는지 **검토할 때만** 사용합니다.
> - 리뷰 시에는 코드를 대신 고치지 말고, 명세와 다른 점·누락·개선점을 **지적과 제안**으로만 남깁니다. (수정은 개발자가 요청할 때만)

## 1. 개요
앱 내에 탑재되는 두 가지 핵심 AI 기능의 세부 규격과 프롬프트/데이터 I/O 정의.
개발자가 구현한 코드가 이 규격에 부합하는지 판단하는 **리뷰 기준점**으로 사용한다.

---

## 2. Feature ①: AI 루틴 추천 마법사 (`AiRoutineWizardModal`)
- **목적**: 사용자가 목표 선택 시 현실적이고 실천 가능한 5가지 루틴을 생성하여 원터치 등록 지원.
- **트리거**: 스케줄표 습관 체크바 우측 `[+]` -> `[✨ AI 루틴 추천 받기]`.
- **입력**:
  - `goalCategory`: '깨끗한 집' | '미라클 모닝' | '운동/체력' | '업무/공부 몰입' | '마음 챙김' | 직접 입력 키워드
  - `existingHabits`: 현재 등록된 습관 목록 (중복 방지)
- **출력 (JSON)**:
  ```typescript
  export interface RecommendedRoutine {
    title: string;
    icon: string; // 예: 🧹, 🌅, 🏃, 📚, 🧘
    category: string;
    description: string; // "아침에 일어나서 침대 시트 정리하기 (2분)"
    frequency: 'daily' | 'weekdays';
    estimatedMinutes: number;
  }
  ```
- **UX 인터랙션**: 5개 항목 중 원하는 항목 다중 체크 후 `[선택한 루틴 추가]` 버튼 클릭 시 즉시 스토어에 등록.
- **오프라인 Fallback**: 네트워크 단절 시 카테고리별 검증된 기본 프리셋 5종 즉시 제공.

## 3. Feature ②: AI 월간 리뷰 자동 요약 리포트 (`AiMonthlyReviewModal`)
- **목적**: 1개월간의 습관 달성률 통계, 다이어리 일기 텍스트, 스케줄 일정 태그를 3중 교차 분석하여 자책 없는 인사이트와 실천 가능한 제안 제공.
- **트리거**: 캘린더 화면 상단 `✨ [AI 월간 리뷰]` 버튼.
- **입력**:
  - `monthlyStats`: 습관별 달성률(%), 최고 스트릭, 요일별 실패/성공률
  - `diaryEntries`: 해당 월 작성된 일기 본문 텍스트 배열
  - `scheduleTags`: 해당 월의 일정 카테고리 및 타이밍 (야근, 외근, 휴일 등 라이프스타일 맥락)
- **출력 (3단 리포트 JSON)**:
  ```typescript
  export interface MonthlyAiReviewReport {
    month: string; // YYYY-MM
    celebration: {
      bestHabit: string;
      longestStreak: number;
      message: string; // 칭찬 및 격려 메시지
    };
    patternAnalysis: {
      vulnerableDay: string; // 예: "목요일"
      vulnerableReason: string; // "야근과 마감으로 인한 피로 누적"
      insight: string; // 구체적 분석 텍스트
    };
    nextMonthSuggestion: {
      actionTitle: string; // "목요일 루틴을 5분 스트레칭으로 가볍게 낮추기"
      reason: string;
    };
  }
  ```
- **UX 인터랙션**: 리포트 카드 팝업 확인 후 `[다이어리에 리포트 스크랩]` 버튼 클릭 시 해당 월 말일 일기에 카드 형태로 영구 보관.
- **오프라인 Fallback**: 
  - 네트워크 단절 시 로컬 계산 기반 **[기본 수치 통계 카드]**(총 실천율 %, 최장 스트릭 달성 습관, 요일별 완주율 그래프)를 우선 표시.
  - 상단에 "오프라인 상태입니다. 네트워크 연결 시 AI 심층 분석이 가능합니다" 안내 배너 및 `[재시도]` 버튼 제공.

## 4. 코드 리뷰 체크리스트

### 공통
- [ ] 출력 타입이 명세의 인터페이스(`RecommendedRoutine`, `MonthlyAiReviewReport`)와 필드명·타입이 일치하는가
- [ ] AI 응답 JSON 파싱 실패/형식 불일치 시 방어 로직이 있는가
- [ ] 네트워크 단절 시 명세된 오프라인 Fallback이 동작하는가
- [ ] 로딩·에러 상태가 UI에 표시되는가
- [ ] API 키 등 민감 정보가 코드에 하드코딩되지 않았는가

### Feature ① 루틴 추천 마법사
- [ ] 트리거 위치(`[+]` → `[✨ AI 루틴 추천 받기]`)가 명세와 같은가
- [ ] `existingHabits`를 넘겨 중복 루틴을 방지하는가
- [ ] 정확히 5개 항목을 보여주고 다중 선택 → 일괄 등록이 되는가
- [ ] 카테고리별 오프라인 기본 프리셋 5종이 준비되어 있는가

### Feature ② 월간 리뷰 리포트
- [ ] 입력 3종(`monthlyStats`, `diaryEntries`, `scheduleTags`)을 모두 수집·전달하는가
- [ ] 리포트가 3단 구조(칭찬 / 패턴 분석 / 다음 달 제안)로 렌더링되는가
- [ ] 메시지 톤이 '자책 없는' 방향인지 (프롬프트에 반영되었는가)
- [ ] `[다이어리에 리포트 스크랩]` 시 해당 월 말일 일기에 저장되는가
- [ ] 오프라인 시 로컬 통계 카드 + 안내 배너 + `[재시도]` 버튼이 표시되는가

### 리뷰 결과 작성 형식
| 심각도 | 의미 |
|---|---|
| 🔴 Must | 명세 위반 또는 버그. 반드시 수정 |
| 🟡 Should | 명세와 다르거나 누락. 수정 권장 |
| 🟢 Nice | 개선 제안 (선택) |

각 항목은 `파일:라인 — 심각도 — 명세 항목 — 내용` 형식으로 작성한다.
