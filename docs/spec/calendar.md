# 📅 캘린더 기능 명세서 (Calendar Spec)

## 1. 개요
월간 그리드를 통해 일정(스케줄)과 해당 날짜의 일기 대표 미디어(사진/그림), 한 달의 습관 성취와 AI 회고를 확인하는 메인 대시보드.

## 2. 셀 레이아웃 (2줄 컬럼 구조)
1. **1행 (상단 - 날짜 및 일정)**
   - 날짜 번호 표시 (오늘 강조).
   - 등록된 스케줄 요약 텍스트 (없을 시 `+` 버튼, 클릭 시 `ScheduleModal`).
2. **2행 (하단 - 대표 미디어)**
   - 다이어리에서 `[캘린더 대표 항목]`으로 지정한 대표 사진 또는 Skia 손글씨/그림 썸네일 자동 연동.
   - 터치 시 해당 날짜의 일기 상세 화면으로 즉시 이동.

## 3. 상단 헤더 & AI 월간 회고 연계
- 월 이동 컨트롤러 (`<`, `YYYY.MM`, `>`, `Today`).
- **`✨ [AI 월간 리뷰]` 버튼**:
   - 분석 입력 소스: **[해당 월 습관 체크 통계] + [다이어리 일기 본문 텍스트] + [스케줄 일정 카테고리/태그(야근/외근 등 맥락)]** 3중 교차 분석.
   - 3단 회고 모달(`AiMonthlyReviewModal`) 오픈:
     1) 🏆 칭찬 및 최고 스트릭 요약
     2) 🔍 무너진 날의 라이프스타일 패턴/원인 분석
     3) 🎯 다음 달을 위한 1가지 스마트 제안
   - 다이어리 월말 페이지로 스크랩 저장 가능.
   - **오프라인 Fallback**: 네트워크 단절 시 로컬 계산 기반 [기본 달성률 수치 요약 카드] 우선 노출.
- 모드 전환 토글 (다이어리 모드 ↔ 가계부 모드[준비중]).
- (옵션) 대표 미디어 갤러리 모아보기 토글.
