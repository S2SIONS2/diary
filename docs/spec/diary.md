# 📖 다이어리(일기장) 기능 명세서 (Diary Spec)

## 1. 개요
텍스트 타이핑과 Skia 기반 손글씨/드로잉, 사진을 조합하여 감성 일기를 작성하고, 주간 습관 트래커 및 AI 회고와 연결되는 화면.

## 2. 일자별(Daily) 템플릿 선택
1. **템플릿 ①: 아날로그 양면 펼침 (태블릿 전용)**
   - 좌측: 미니 캘린더 + 현재 주차 + **주간 습관 트래커 연동(7일 잔디 + 체크)** + 3줄 요약.
   - 우측: 가로 4줄 자유 기록.
2. **템플릿 ②: 2분할 가변 리사이징 (공용)**
   - 미디어 영역(사진/드로잉) + 텍스트 영역(타이핑/손글씨).
   - `ResizableSplitBar`로 비율 자유 조절.
3. **템플릿 ③: 1칸 자유 캔버스 (공용)**
   - 텍스트, 손글씨, 사진을 원하는 좌표에 무제한 배치.

## 3. 모바일 다이어리 전용 규칙
- 모바일은 템플릿 ② 또는 ③ 중 1일 세로 뷰로 렌더링.
- **모바일 습관 위젯 (`MobileHabitAccordionBar`)**:
  - 상단 헤더에 **`[오늘 체크 칩바]`** 기본 노출.
  - 터치 시 아래로 **`[주간 7일 달성 닷(Dot) 잔디]`**가 부드럽게 펼쳐지는 접이식 미니 위젯 제공.

## 4. 대표 항목 지정 & AI 연계
- **캘린더 대표 항목 지정(★)**: 특정 사진/드로잉을 대표 항목으로 지정 시 월간 캘린더 2행에 자동 썸네일 노출.
- **AI 월간 회고 분석 연계**: 일기 본문 텍스트는 AI 월간 회고 분석의 핵심 감성/맥락 데이터 소스로 활용.
- **AI 리포트 스크랩**: 생성된 AI 월간 회고 리포트 카드를 해당 월 마지막 일기 페이지에 저장 가능.
