# ⏱️ 스케줄표(플래너) 기능 명세서 (Planner Spec)

## 1. 개요
하루 24시간 타임라인 일정, 반복 습관 루틴, 할 일(To-Do) 목록을 직관적으로 관리하는 화면.

## 2. 레이아웃 (상/중/하 3단 하이브리드)
1. **상단: 24H 타임라인 (Timeline Block)**
   - 00:00 ~ 24:00 시간대별 슬롯, 현재 시각 라인.
   - 터치/드래그로 일정 블록 생성, 터치 시 `ScheduleModal` 오픈.
   - 캘린더 일정과 실시간 양방향 동기화.
2. **중단: 오늘의 루틴 & 습관 체크바 (Daily Habit Bar)**
   - 가로 스크롤 가능한 Chip 형태로 오늘 실천할 습관 목록 표시.
   - 칩 구성: `[이모지/아이콘]` + `[습관명]` + `[스트릭 🔥]` + `[원터치 체크 토글]`.
   - 우측 끝 `[+ 루틴 추가]` 버튼 -> 직접 추가 또는 `[✨ AI 루틴 추천 마법사]` 오픈.
3. **하단: 투두 리스트 (Daily To-Do List)**
   - 1회성 할 일 등록, 완료 체크, 취소선, 정렬.

## 3. 필터 시스템
- `전체`, `개인용`, `회사용` 기본 칩 + 사용자 커스텀(`+`) 카테고리.
